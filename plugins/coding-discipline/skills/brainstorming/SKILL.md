---
name: brainstorming
description: Discuss implementation choices when the user explicitly requests design help or wants to decide a tradeoff before coding.
disable-model-invocation: true
license: MIT
---

Check the relevant project context and summarize the intended outcome, constraints, and what would count as success.

Compare the practical options that would change the outcome, recommend one, and explain its main tradeoff. Use existing project conventions for reversible details. Ask about unresolved choices only when they would materially change the result or create substantial rework. If the user asked to approve a design before implementation, present the proposed design for that decision.
